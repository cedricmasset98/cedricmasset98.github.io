# cedricmasset.ch

Site personnel de Cédric Masset, publié avec GitHub Pages sur le domaine `cedricmasset.ch`.

- `index.html` : la page unique du site
- `css/`, `js/`, `images/`, `fav/`, `libs/` : styles, scripts, images, favicons et Font Awesome
- `scss/`, `gulpfile.js`, `package.json` : sources du thème (template *devportfolio* de Ryan Fitzgerald, licence MIT)
- `CNAME` : domaine personnalisé utilisé par GitHub Pages
- `.nojekyll` : sert les fichiers tels quels, sans traitement Jekyll

Toute modification poussée sur `main` est publiée automatiquement en une minute environ.
