# cedricmasset.ch

Site personnel de Cédric Masset, publié avec GitHub Pages sur le domaine `cedricmasset.ch`.

- `index.html` : la page unique du site
- `css/styles.css` : feuille de style du site, éditée directement (pas d'étape de build) ; les couleurs principales sont des variables CSS en tête de fichier
- `js/scripts.js` : script du site (timelines, menu), chargé tel quel
- `images/`, `fav/`, `libs/` : images, favicons et Font Awesome
- Thème d'origine : template *devportfolio* de Ryan Fitzgerald (licence MIT)
- `CNAME` : domaine personnalisé utilisé par GitHub Pages
- `.nojekyll` : sert les fichiers tels quels, sans traitement Jekyll

Toute modification poussée sur `main` est publiée automatiquement en une minute environ.
